# Bundled font

`Cantarell-Regular.ttf` is the Cantarell Regular font from the GNOME Cantarell project.
It is used to render readable UI text through an `ab_glyph`-rasterized single-channel
atlas. The font is distributed under SIL Open Font License 1.1; see `OFL.txt` for the
copyright notice and full license. The current atlas covers printable Basic Latin;
unsupported characters use the question-mark glyph.
